Reusable .hbs Region Primitives

The Base suite separates an HTML page into three independent Handlebars (.hbs) building blocks: Header, Body, and Footer. Each package owns its templates, styles, and browser runtime so higher-level apps—Monaco studios or future HTML builders—can compose them freely.

The 3 Base Packages

monaco-json-studio-base-header

title, file-picker, select, and actions headers powered by .hbs & dom-primitive-bindings.

Overview Repo Docs npm GitHub

monaco-json-studio-base-body

single, double, and triple pane workspace .hbs layouts paired with the Monaco mounting runtime.

Overview Repo Docs npm GitHub

monaco-json-studio-base-footer

cursor, note, status, and stats footers with live cursor and JSON validation updaters.

Overview Repo Docs npm GitHub

How Consumers Compose Base

monaco-json-studio-base-header (.hbs + dom-primitive-bindings) ─┐
monaco-json-studio-base-body   (.hbs 1/2/3 panes + Monaco)      ─┼─► Studio / HTML App
monaco-json-studio-base-footer (.hbs + cursor/stats updaters)   ─┘

See Studio Docs for how single, double, and triple assemble these blocks.
